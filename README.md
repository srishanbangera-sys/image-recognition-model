# Image Recognition Model using TensorFlow

A simple **image recognition model built using TensorFlow** as part of my Machine Learning learning journey.

The project focuses on understanding the basics of **image classification, neural networks, model training, validation, and prediction** using TensorFlow and Keras.

## 📌 About the Project

This project was created while learning **Machine Learning with TensorFlow**.

The main goal was to understand how a neural network can learn patterns from images and classify them into different categories.

The project covers the basic workflow:

**Dataset → Preprocessing → Model Building → Training → Validation → Prediction**

## 🛠️ Technologies Used

* Python
* TensorFlow
* Keras
* NumPy
* Matplotlib
* Jupyter Notebook / Google Colab

## 🧠 What I Learned

* Loading and preparing image datasets
* Image preprocessing and normalization
* Understanding image dimensions and channels
* Building neural networks using Keras
* Training an image classification model
* Using training and validation data
* Evaluating model performance
* Making predictions on images
* Understanding accuracy and loss during training

## ⚙️ Model Workflow

1. Load the image dataset
2. Resize images to a consistent size
3. Normalize pixel values
4. Split data into training and validation sets
5. Build the TensorFlow/Keras model
6. Train the model on the dataset
7. Evaluate the model
8. Use the trained model to recognize new images

## 📊 Training

The model is trained using the training dataset and evaluated using validation data.

During training, the model learns visual patterns from the images and gradually improves its ability to distinguish between different classes.

Training metrics such as **accuracy** and **loss** are used to understand the model's performance.
